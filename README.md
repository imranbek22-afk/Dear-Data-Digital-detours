# Digital Detours

This Dear Data project investigates how a planned phone-use session can turn into a distraction.

## What I am recording

For each phone-use session, I record:

- the day
- the time period
- what I intended to do
- what I ended up doing
- whether I got distracted
- how long the session lasted
- whether I completed my original task

## Data collection

I will record 2-3 sessions per day

## Current progress

I am currently setting up the project and will begin collecting genuine observations.
